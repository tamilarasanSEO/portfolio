# Tamilarasan | Digital Marketing Portfolio (Static Version)

This is a modern, high-performance static portfolio website for Tamilarasan, a Digital Marketer specializing in Performance Marketing, Meta Ads, and SEO.

## 🚀 Transition to Static
The project has been migrated from Next.js to a pure **Bootstrap 5.3.8** static page. This change ensures:
- **Instant Load Times**: No server-side processing or client-side hydration.
- **Easy Deployment**: Can be hosted on any static platform (GitHub Pages, Netlify, Vercel, or even a local folder).
- **Simplified Maintenance**: All content is in a single `index.html` file.

## 📂 Project Structure
- `index.html`: The main website file containing all sections.
- `style.css`: Custom CSS for branding, animations (wave effect), and interactive elements.
- `public/`: Directory containing all assets (images, icons, and favicons).

## 🛠️ Features
- **Hero Section**: Dynamic entrance with a "wave" animation.
- **Downloadable Resume**: A dedicated button in the header that generates a PDF version of the portfolio using the browser's print engine.
- **Experience & Skills**: A detailed breakdown of professional history and expertise.
- **Latest Works**: A portfolio of 6 high-impact digital marketing projects.
- **Contact Form**: A functional form powered by `formsubmit.co`.

## 🌐 How to View
Simply open `index.html` in any modern web browser.
